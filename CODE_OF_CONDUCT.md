# Community Code of Conduct

ReproCert is intended to support rigorous technical collaboration.

Participants are expected to:

- discuss ideas, evidence, and code without personal attacks;
- separate technical disagreement from judgment about people;
- provide reproducible evidence when making material technical claims;
- respect confidentiality, privacy, and intellectual-property boundaries;
- avoid harassment, discrimination, threats, or deliberate disruption;
- accept good-faith correction when evidence changes.

Maintainers may edit, hide, lock, or remove contributions that materially violate these expectations, expose sensitive information, or disrupt technical collaboration.

For ordinary disagreements, prefer a minimal reproduction, failing test, benchmark, specification reference, or concrete counterexample over escalation.
