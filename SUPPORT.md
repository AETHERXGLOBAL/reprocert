# Support

ReproCert is an open-source public-alpha project.

## Use GitHub Issues for

- reproducible bugs;
- installation or compatibility problems;
- documentation defects;
- focused feature proposals.

Use the repository's structured issue forms whenever possible.

## Before opening an issue

- search existing issues;
- reduce the problem to a non-sensitive minimal reproduction;
- include the ReproCert version/commit, Python version, and operating system;
- distinguish an execution error from a failed claim when describing the problem.

## Not appropriate for public issues

Do not post:

- credentials or tokens;
- private customer information;
- confidential source code;
- trade secrets;
- sensitive exploit details.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md).

## Commercial or enterprise engagement

This repository is the public open-source project surface. Enterprise evaluation, integration, or strategic engagement with AETHER X GLOBAL is separate from community issue support.
